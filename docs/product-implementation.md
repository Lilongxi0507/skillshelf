# SkillShelf 本机共享产品实施记录

本次以用户批准的完整产品计划为验收依据。产品是同一设备多个 Agent 共用的技能与 MCP 管理器，独立于云面板；发布 npm 需要用户另行明确授权。

## 约束

- 在现有 TypeScript 核心、内容寻址存储、锁和事务机制上实现；CLI、接入与 MCP 入口共用状态。
- 技能包是完整安装、版本切换、回滚与卸载单位；子技能是读取与 Agent 启用单位。
- 默认共享原文件，不隐式复制；原生加载证据与注册、链接成功分别记录。
- 保留旧安装、用户修改、其他管理器内容。去重和覆盖必须确认具体预览并重新校验。
- 不执行下载技能的脚本、安装钩子；密钥不进入目录、导出或诊断报告。
- 本地开发和隔离验证，不修改生产服务；不提交、推送或发布。
- 平台与 Agent 的未经实测项目必须明确标记，不能以模拟测试代替原生验证。

## 模型契约

精选包固定为 `taste`、`matt-pocock`、`superpowers`、`gitnexus`、`ui-ux-pro-max`、`archify`、`skillshelf-web-search`、`skillshelf-media-generation`。成员数量从清单计算。

子技能保留来源标识、原生名称、包内路径、主分类、附加分类、技术标签、中文用途和场景。包保持上游布局，成员入口指向包内原始目录。目录分类不生成文件副本。

十二类：前端与界面、后端与数据存储、全栈与应用交付、移动与桌面、架构与代码理解、测试/调试/安全、部署与运维、AI 与 Agent 开发、数据分析与可视化、研究与信息检索、文档与协作、图像/视频/创意。

旧记录保持可读，迁移仅生成预览，用户明确选择父包后补全；不通过加载状态自动下载、删除或重写项目锁。

## 实施决策

- 沿用当前用户工作区，不创建分支或提交；所有源码变更可在工作区审查。
- 开发临时环境位于数据盘独立运行目录，构建在独立容器中执行；最终产物单独保留。
- 各模块顺序实施并单独复核；共享模型稳定后再接入下一模块，避免并发重写核心契约。

## 验证记录

本次实现后的隔离验证使用 Node.js 24，未访问 npm 账号、未发布、未修改真实 Agent home：

- `npm run build` 通过，TypeScript 与内置目录同步完成。
- 重新生成并校验 8 个完整技能包、83 个子技能和目录；候选交付物为 8 个技能包、1 个目录包和 1 个 CLI 包，共 10 个 npm 包。
- 完整 Node 回归为 `162 tests / 160 passed / 0 failed / 2 skipped`。跳过项是 Windows 原生 ACL 和需要显式 CLI tarball 环境变量的安装测试；真实 CLI tarball 安装另行完成 `1/1`。
- CLI PTY 冒烟覆盖 40、80、120 列、无颜色、窗口重排、Esc/Ctrl-C 取消、包级搜索命中子技能、双选预览并拒绝写入，4 组均通过。
